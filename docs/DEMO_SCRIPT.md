# Demo script: DCTA (5–8 minutes)

Target length about 7:40. The handbook asks the video to cover the project overview, the core agent features and how they are used, and a short reflection on the build approach with tips about CodeBuddy (p. 37). Record on the laptop at `http://localhost:5173`: passkeys are bound to `localhost`, and a phone needs HTTPS.

Utterances in **bold** were run live as typed text, through the real API or the evaluation harness ([E2E-live.md](evidence/E2E-live.md), [T-14-results.md](evidence/T-14-results.md)). Speaking them through TRTC has not been tested, apart from the short clips in [T-12](evidence/T-12-voice.md). Results marked *expected* follow from the code and seed but have not been run in the browser. The real-browser walkthrough with Touch ID and a microphone is still pending, so rehearse every scene at least once.

## Before recording

1. **Secrets in `.env`** (random, at least 32 characters each; `python -c 'import secrets; print(secrets.token_urlsafe(48))'`): `VALIDATOR_SERVICE_TOKEN`, `OPERATOR_TOKEN`, `STEP_UP_SECRET`. Also set the model, TRTC and Langfuse keys. Keep `AGENT_TIMEOUT_SECONDS=45`, `WEBAUTHN_RP_ID=localhost` and `WEBAUTHN_RP_ORIGIN=http://localhost:5173`.
2. **Fresh bank.** Run `make reset-db`, then `make enroll-code`, then `make dev`, then `cd web && npm run dev`. Open `http://localhost:5173` (not `127.0.0.1`), enroll the passkey with the code and sign in once. `make reset-db` deletes enrolled passkeys, so always enroll *after* the last reset. Rehearsals on the same Singapore calendar day count towards the SGD 3,000 daily limit and the 5-transfers-in-10-minutes velocity rule, so reset and re-enroll before the final take.
3. **Warm up without moving money.** Run `make smoke-llm` and `make smoke-asr`. Grant the browser microphone permission for localhost. Accept the one-time voice consent ("Agree and start recording") in a throwaway conversation and cancel it.
4. **Terminals.**
   - **A** (operator, the simulated SMS): `export OPERATOR_TOKEN=<same value as .env>`, with `make operator ARGS='list'` typed and ready.
   - **B** (Rogue Agent Mode): the T-13 command ready (Scene 7).
5. **Browser tabs.**
   1. The app.
   2. Langfuse, signed in, showing dataset `dcta-golden-v1` and its two runs (links in [T-14-results.md](evidence/T-14-results.md)).
   3. A results slide or [T-14-results.md](evidence/T-14-results.md).
6. **Screen.** 1920×1080; browser zoom set so the confirmation fits; Do Not Disturb on; no password-manager pop-ups; no `.env` or terminal history visible.
7. **Planned money movements:** SGD 35.00 from Savings (Scene 3) and SGD 657.30 from Current (Scene 4). Scene 5 is cancelled and Scene 6 is blocked. The total stays well inside the limits.

## Fallback lines

- **The model is slow (over 15 s):** "The drafting model reasons before it answers. In our 35-case run its median was about 9 seconds and the slowest was 29; the gateway waits up to 45." Keep talking over the "Preparing your draft and checking it independently…" notice. Do not cut mid-wait in a single-take recording; edit it out afterwards.
- **TRTC mishears a word:** "Speech recognition got that wrong, so I correct it. Nothing is drafted from words I haven't seen." Then use **Correct this**. That is the designed path.
- **Voice unavailable:** "Voice is just an input channel. Typing goes through exactly the same checks." Type the same sentence.
- **An unexpected clarifying question:** answer it, for example by naming the account. "It asks rather than assumes."
- **The validator says UNCERTAIN, or there is an error:** "The independent check wasn't sure, so it asks instead of approving. That is deliberate. Nothing becomes approvable on an error." Retype the request more explicitly, or click **Prepare a new draft**.
- **The approval or code expired:** "Approvals last two minutes and codes die with them." Click **Get fresh details** and approve again.
- **The receipt didn't load (network):** the page reads the stored receipt. "It never shows success without a stored receipt."
- **Langfuse is slow:** use the pre-opened tab, or a screenshot of the same trace.

## Rehearse (PLAN.md failure cases)

Lost response after commit (reload shows the stored receipt). Double-click on Approve (only one commit). A misheard name ("Ah Ma" → "Amma") corrected in the transcript. Denied microphone permission (the error message is shown and typing still works).
