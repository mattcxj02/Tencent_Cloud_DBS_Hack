# evals/usability

Kit for the exploratory usability comparison (about five consenting testers, synthetic
accounts, DCTA chat `#/chat` vs the conventional form `#/baseline`, alternating order).

| File | Purpose |
|---|---|
| `protocol.md` | Question, consent and retention, setup, the three tasks with correct outcomes, order, measures, what to do afterwards |
| `facilitator_script.md` | What to say and record in each ≈20-minute session |
| `results_template.csv` | Header only: one row per tester × interface × task. Contains no data until sessions actually happen |

No participant data exists yet. Never add rows that were not observed. Results contain
participant codes only; notes and any session audio are deleted by 15 November 2026.
